# DDNS-GO Home Assistant add-on

This add-on packages the upstream [jeessy2/ddns-go](https://github.com/jeessy2/ddns-go) release for Home Assistant OS.

It supports Aliyun DNS, Tencent Cloud, DNSPod, Cloudflare, Huawei Cloud and other DNS providers. The upstream binary is pinned to a specific release and verified with the release SHA-256 checksum during the image build.

See [DOCS.md](DOCS.md) for installation and Aliyun DNS configuration.
